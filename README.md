# ☁️ Cloud Cost Optimizer Dashboard

A lightweight Streamlit dashboard that analyzes AWS cloud service usage (EC2, S3, Lambda, RDS) and provides cost breakdowns along with optimization suggestions.

---

## 🚀 Features

- Upload or use default cloud usage data.
- Calculate monthly AWS cost across services.
- See real-time cost optimization tips.
- Clean and dark-themed UI built with Streamlit.
